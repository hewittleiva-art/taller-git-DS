# taller-git-DS

## Descripción
Taller de práctica Git y GitHub. Contiene una página principal, una página con datos personales y una hoja de vida, todo con estilos CSS.

## Archivos del proyecto
- index.html → Página principal con menú de navegación
- pagina1.html → Datos personales
- pagina2.html → Hoja de vida
- estilos.css → Hoja de estilos compartida
- README.md → Documentación del proyecto

## Tecnologías usadas
- HTML5
- CSS3
- Git y GitHub
- XAMPP
